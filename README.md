# Frame Window Counter — Android Port

Android32/Android64 port of **Frame Window Counter v1.1.4**.

The build workflow produces one combined `.geode` package containing both:

- `c0nscious.frame_window.android32.so`
- `c0nscious.frame_window.android64.so`

The port uses Geode’s cross-platform file picker for importing/exporting `.fwc`, `.json`, `.gdr`, `.gdr2`, `.slc`, and audio files. The Windows `O` hotkey remains Windows-only.

Source: https://github.com/hyper-5/frame-window-counter
